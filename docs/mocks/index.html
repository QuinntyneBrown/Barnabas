Barnabas — static mock catalogue

Barnabas is a lending-and-helping board scoped to a single congregation (St. Aidan's, in this set). Members post something to lend, give away, or sell, or post time they're offering — a ride, tutoring, help moving. Everything below is plain HTML and CSS: no build step, no framework, no CDN. Open any file directly from the filesystem in a browser. A single shared styles.css carries the token system, and a tiny mocks.js only powers a couple of confirmation dialogs — every page is fully usable with JavaScript turned off.

Mobile-first: every mock is designed for 360px first, and re-flows at 768px and 1280px. Where a layout changes materially between breakpoints, that's noted in an HTML comment at the top of the file.
